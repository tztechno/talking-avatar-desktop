# Talking Avatar デスクトップアプリ使用マニュアル

[English version](MANUAL.en.md)

Talking Avatar は、入力した文章を読み上げながら、2Dアバターや写真が一緒に喋るデスクトップアプリケーション（macOS / Windows）です。
声に合わせて口がリアルタイムに動き、まばたきをし、頭部が自然に揺れます。
内蔵アバターのほか、お手持ちの顔写真（ポートレート）や自作のイラストアバターを読み込んで喋らせることができ、動画ファイル（WebM / MP4）としての保存も可能です。

すべての処理はローカル環境（お使いのPC上）で実行されるため、入力した文章や写真データが外部サーバーへ送信されることはありません。

---

## 1. アプリのインストールと起動

### macOS の場合
1. 提供された DMG ファイル（例：`Talking-Avatar_0.1.0_aarch64.dmg`）をダブルクリックして開きます。
2. 表示されるウィンドウで `Talking Avatar` アイコンを `Applications`（アプリケーション）フォルダにドラッグ＆ドロップします。
3. アプリケーションフォルダから `Talking Avatar` を起動します。
   - ※未署名アプリの警告が出た場合は、**Finder でアプリを右クリック（または Control + クリック）→「開く」** を選択し、ダイアログで「開く」をクリックしてください。

### Windows の場合
1. 提供されたインストーラー（例：`Talking-Avatar_0.1.0_x64-setup.exe` または `.msi`）をダブルクリックして実行します。
2. 画面の指示に従ってインストールを完了させ、デスクトップまたはスタートメニューから起動します。
   - ※Windows Defender SmartScreen の警告が表示された場合は、**「詳細情報」→「実行」** をクリックしてください。

## 2. 画面構成と各部説明

| 画面エリア | 機能と説明 |
|---|---|
| **ステージ（画面左）** | アバターが表示されるエリアです。顔写真やアバターのフォルダ・ZIPファイルをドラッグ＆ドロップできます。 |
| **Background（背景設定）** | アバターの背景を選択します。<br>・**Transparent（透明）**<br>・**Colour（背景色指定）**<br>・**Chroma green（グリーンバック・動画合成用）** |
| **Load photo** | お手持ちの顔写真（JPG / PNG / WebP）を読み込みます（ポートレート推奨）。 |
| **Load folder / Load .zip** | 自作のアバターパーツ一式が含まれるフォルダまたは ZIP ファイルを読み込みます。 |
| **内蔵アバター選択欄** | ・**Sample photo**：写真ベースのサンプルアバター<br>・**Illustration**：イラスト形式のデフォルトアバター |
| **Mark mouth** | 写真アバター読み込み時、自動認識に失敗した場合や位置を調整したいときに手動で口角2点を指定します。 |
| **Mouth shapes (debug)** | 口の形（A, I, U, E, O, X）の手動テスト表示と動作 FPS を確認できます。 |
| **音声エンジン選択（画面右上）** | ・**Kokoro (AI voice, English)**：自然な抑揚の高品質 AI 音声合成（英語専用・ONNX/WebGPU）<br>・**Browser voice / System**：OS ネイティブの音声合成（**日本語を含む多言語対応**） |
| **Voice / Speed** | 音声の種類（話者）と読み上げ速度（0.5倍〜2.0倍）を調整します。 |
| **テキスト入力欄** | 読み上げさせたい文章を入力・ペーストします。発話中は読んでいる文がハイライト表示されます。 |
| **Speak / Pause / Stop** | 読み上げの開始・一時停止・停止を行います。 |
| **Speak & record video** | 読み上げとアバターのアニメーションを同時にキャプチャ録画し、動画ファイルとして保存します。 |
| **ステータス表示欄** | モデル読み込み進捗や各種通知、エラー情報が表示されます。 |

## 3. 基本的な使い方

### 3.1 日本語の文章を読み上げる
1. 音声エンジンで **「Browser voice」** を選択します。
2. **Voice** のドロップダウンから日本語の音声（例: `Kyoko`, `Otoya`, `Microsoft Nanami` など）を選択します。
3. テキスト入力欄に日本語の文章を入力します。
4. **「Speak」** ボタンをクリックすると、アバターが音声に合わせて口パクしながら喋り始めます。

### 3.2 英語を高音質な AI 音声で読み上げる (Kokoro)
1. 音声エンジンで **「Kokoro (AI voice, English)」** を選択します。
2. 初回のみ **「Download & load model」** ボタンが表示されますのでクリックします（約 90 MB の軽量 ONNX モデルがダウンロードされ、ローカルにキャッシュされます）。
3. 読み込みが完了すると、男女28種類以上の自然な AI 音声が利用可能になります。
4. **Voice** からお好みの声を選び、英文を入力して **「Speak」** をクリックします。

## 4. 写真アバターの使い方 (Photo Avatar)

正面を向いた人物写真を用意するだけで、瞬時に喋るアバターに変換できます。

1. **「Load photo」** をクリックするか、写真をステージ上にドラッグ＆ドロップします。
2. MediaPipe Face Landmarker により、目・口・顎の位置が自動検出されます。
3. WebGL メッシュワープ技術により、音声に合わせて自然にあごが開き、唇が伸縮し、自動的にまばたきを行います。
4. ※横顔や特殊な照明等で自動検出できなかった場合は、画面の指示に従い、写真上の「口の左端」と「口の右端」をクリックして手動設定してください。

## 5. 自作イラストアバターの読み込み (Custom 2D Avatar)

パーツ分けされた自作イラストをフォルダまたは ZIP 形式で読み込むことができます。

### 必要なファイル構成
- `avatar.json` (設定ファイル)
- `base.png` (目・口のない顔ベース画像)
- `eyes_open.png`, `eyes_half.png` (任意), `eyes_closed.png` (まばたき画像)
- `mouth_X.png` (閉じ口・静止時), `mouth_A.png`, `mouth_I.png`, `mouth_U.png`, `mouth_E.png`, `mouth_O.png` (母音別の口画像)

すべて同じキャンバスサイズ（例: 512x512）で作成して配置します。

---

## 6. 動画の録画・書き出し (Video Export)

1. 背景を **「Chroma green（グリーンバック）」** またはお好みの背景に設定します。
2. 文章を入力し、**「Speak & record video」** をクリックします。
3. 読み上げ完了と同時に、動画ファイル（`.webm`）が自動的に保存されます。
4. 動画編集ソフト（Premiere, DaVinci Resolve, Final Cut Pro, OBS等）でクロマキー合成して使用できます。
